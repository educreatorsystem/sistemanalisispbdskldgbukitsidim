# Sistem Analisis PBD - SEKOLAH KEBANGSAAN LADANG BUKIT SIDIM

Fail ini disediakan untuk GitHub Pages.

## Kandungan
- `index.html` - fail utama sistem.

## Cara publish di GitHub Pages
1. Cipta repository baharu di GitHub.
2. Upload fail `index.html` ke root repository.
3. Pergi ke **Settings > Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`.
6. Simpan dan tunggu pautan GitHub Pages dijana.
